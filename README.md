## The entry

> 1% left. Tell Mom I loved her. Tell my charger I never even liked it.

One line, 69 characters — the last text a dying phone sends at one
percent, in its own voice. It opens like a sentimental goodbye ("Tell
Mom I loved her"), then swerves: the phone's real grudge is against its
charger, a relationship only a phone has. No battery pun, no wasted
words, and the punch lands on the very last word.

## How it works

`main.py` writes the line above to `/output/entry.txt`. Nothing else:
deterministic, no network, no input, no dependencies beyond Python 3.

```sh
python3 main.py
cat /output/entry.txt
```
